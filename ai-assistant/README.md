# QuickBite AI Assistant

A lightweight food recommendation assistant created as a separate folder inside the QuickBite project.

## Run locally

From the project root:

```bash
node ai-assistant/server.js
```

Then open:

```text
http://localhost:3001
```

## Features

- chat-style food suggestions
- budget-aware recommendations
- vegetarian / non-veg / spicy / dessert filters
- examples for quick testing
